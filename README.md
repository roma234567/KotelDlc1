# KotelDLC Safe Scaffold

KotelDLC is a Java 21 project that mirrors the requested Minecraft-client style layout while staying safe and fair-play oriented.

## What is included

- A client entry point with a custom main-menu model.
- A module manager, settings system, event bus, themes, resource loading helpers, and GUI components.
- Cosmetic and quality-of-life module placeholders that can be extended for single-player, private worlds, accessibility, or visual customization.
- Safety-gated placeholders for names commonly associated with competitive automation; these classes do not implement aim automation, attack automation, anti-cheat bypasses, or server-abusive behavior.
- A small Python launcher stub for local profile/settings handling.

## What is intentionally excluded

- Kill aura, trigger bot, aim assist, hitbox expansion, anti-cheat bypass, packet manipulation for evasion, or any code intended to cheat on public servers.
- HWID collection or network license checks. The anti-leak package contains local-only integrity notices.

## Build

```bash
./gradlew build
```

If a Gradle wrapper is not present, use a system Gradle installation:

```bash
gradle build
```

## Run scaffold demo

```bash
gradle run
```
